# Vending Machine Pickup Line

One pickup line a vending machine would use on a passing human, written for
make.fun's "One Line, One Minute: The Vending Machine Pickup Line Contest".

## The line

> Hey — I'm the machine in the corner, and I've been humming since you walked by. Press B7 and let me drop you something sweet.

Why it works: it is spoken by the machine itself, in the first person; it
draws on the machine's own world (its hum, its buttons, its drop); the
punch lands in the last few words; and it stays short, speakable and
charming rather than creepy.

## How to run

```sh
python3 main.py
```

This writes the single line to `/output/entry.txt` (creating `/output` if
needed). Python 3, standard library only.
